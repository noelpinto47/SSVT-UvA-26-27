-- DESIGN CHOICES

The strength of a set of properties is the percentage of mutants that they
kill. A mutant is created by applying a mutator to the output of the
function under test. All properties are then run on the mutated output. If
at least one property fails, the mutant is killed. If all properties still
pass, the mutant survives.

'mutantResults :: Eq a => Int -> [Mutator a] -> [Prop a] ->
FunctionUnderTest a -> Gen [[Bool]]' generates the correct number of
mutants using vectorOf. For each mutant, it picks a random mutator with
'elements' and a random positive number input. It then uses the mutate'
function from Mutation.hs, which returns one Bool for each property. The
input has to be positive because an input of 0 makes every element of the
multiplication table 0.

Mutators are random generators, so one mutator can produce a lot of
different mutants. This is why a large number of mutants is generated
rather than one mutant per mutator. 'isKilled :: [Bool] -> Bool' checks if
at least one property returned False.

'strength' removes the equivalent mutants before it calculates the
percentage. mutate' returns an empty list when the mutant is the same as
the original output. An equivalent muntant cannot be killed by any correct
property, so counting it would unfairly lower the strength. If every
mutant is equivalent, strength will return 0 so it doesn't have to divide
anything by zero.



-- TESTS

The function was tested with all five multplication table properties and
with only prop_moduloIsZero. If strength works correctly, the weaker set
with one property should give a lower percentage than the full set.

The mutators used were addElements, removeElements and anyList from
Mutation.hs with 1000 mutants per run.



-- TEST RESULTS

All five properties:

Strength of properties: 100.0%

Only prop_moduloIsZero (8 runs):

62.3, 63.4, 63.2, 64.6, 63.2, 62.7, 63.3, 66.0

The full set of properties kills every non-equivalent mutant. With only
prop_moduloIsZero the strength drops to around about 63%. Since
removeElements keeps the first elements of the table, these are all
still multiples of the input, so prop_moduloIsZero can never kill them.
Around a third of the mutants come from removeElements, which matches the
roughly 37% that survive.



-- LIMITATIONS

Strength is a random estimate, so the result changes between runs.
With 1000 mutants the results for prop_moduloIsZero varied between about
62% and 66%. Using more mutants would make the estimate more consistent but
slower.
