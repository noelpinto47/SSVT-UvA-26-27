1. APPROACH

The transitive closure of R is the smallest transitive relation that contains R.
R @@ R gives the pairs reachable in exactly two steps, R @@ R @@ R in three, and so on.
I start with current = R and repeat one round: next = current ∪ (current @@ R)
I stop when next has the same pairs as current (a fixed point). step does one round and loop repeats it until nothing changes.
Two details keep the result clean: I nub the input first so duplicates don't carry through, and I sort the result at the end because the exercise asks for an ordered list of pairs.

2. PROPERTIES

Properties are tested in Exercise 6.

4. RESULTS

trClos gives the expected result for the example from the exercise, [(1,2),(1,3),(1,4),(2,3),(2,4),(3,4)].
It also handles four other cases:
- an input not in order
- a cycle
- a duplicate pair
- the empty relation
In all of them the result is ordered and has no duplicates.
