Design Report

1)Definitions
1.1) Binary relations -  a binary relation associates some elements of one set called the domain with some elements of another set (possibly the same) called the codomain.[
Since they are defined on sets which are by default comprised of distinct(non duplicate) elements that means that the type Rel a = [(a,a)] must also contain no duplicates.

1.2) Symmetric closure
In mathematics, the symmetric closure of a binary relation R on a set X is the smallest symmetric relation on X that contains R ie 
The symmetric closure S of a Relation R on a set X is given by
S = R ∪ {(y,x) : (x,y) ∈ R}
So for a set R = {(1,2), (2,3)}
S = {(1,2), (2,1), (2,3), (3,2)}

1.3)Implementation
symClos :: Ord a => Rel a -> Rel a
Constraint: A type a for which an order of elements can be defined(so elements can be compared to each other). 'a' can be Int, Char, String, Bool etc.
Input: Rel a
Output: The symmetric closure of the Rel over a.

The symmetric closure is implemented as
symClos r = nub $ sort $ r ++ [(y,x) | (x,y) <- r]

ie for each element in the Rel r (x,y) it appends (y,x) as a new element to the initial list r(thus creating a new list)
This list os sorted lexicographically using sort and then duplicates are removed using nub

So for 
S = {(1,2), (2,3)}
it appends (2,1) and then (3,2)
leading to {(1,2), (2,3), (2,1), (3,2)}
And then when sorted it gives
S = {(1,2), (2,1), (2,3), (3,2)}

Note: 
For the empty set [] the result is also the empty set []
If the input list does contain duplicates then those would be removed as they do not add anything but not having duplicates is not enforced by the input type type Rel a = [(a,a)] itself.
